# IBM Plex Sans

The bundled fonts are the official IBM Plex Sans variable Roman and Italic fonts from IBM's Plex repository, retrieved on 1 November 2026:

- [Official font directory](https://github.com/IBM/plex/tree/master/packages/plex-sans-variable/fonts/complete/woff2)
- [Font download](https://raw.githubusercontent.com/IBM/plex/master/packages/plex-sans-variable/fonts/complete/woff2/IBM%20Plex%20Sans%20Var-Roman.woff2)
- [Italic font download](https://raw.githubusercontent.com/IBM/plex/master/packages/plex-sans-variable/fonts/complete/woff2/IBM%20Plex%20Sans%20Var-Italic.woff2)
- [Matching licence](https://raw.githubusercontent.com/IBM/plex/master/packages/plex-sans-variable/fonts/complete/woff2/license.txt)

Local files `IBMPlexSansVar-Roman-v2.woff2` and `IBMPlexSansVar-Roman.woff2` contain the same unmodified 230,368-byte font. SHA-256: `e978248b6b56da9e372975322a98dd9a51135d1b375e32ed6d5ca69f3aab792d`.

`IBMPlexSansVar-Italic.woff2` contains the unmodified 262,364-byte italic font. SHA-256: `57c2e5e2d0a16054e83315a312d2d5d0166e4a6f5b27dbed28d7d9d05b5e4292`. The italic face gives the notes genuine IBM Plex Sans italics while keeping synthetic font styles disabled.

The stylesheet uses the versioned filename to avoid cached copies of the original invalid asset. Its CSS family is `IBM Plex Sans`; Chrome reports the font's internal family as `IBM Plex Sans Var`. All application text and native form controls inherit this family. The font works offline, with no external font-service requests.

The SIL Open Font License is bundled as `IBM-Plex-LICENSE.txt`.
